🧭Getting around

Trakisilo is organized as views on a left activity rail, with a board rail inside the Board view. Everything below is chrome — learn it once and every view works the same way.

Views

What it does. Board, Chronicle, Clips, Calendar, Time, Processes — icons in the activity rail on the left. Settings and Help sit at the rail's bottom.

How to use it. Click a rail icon, or jump via ⌘K.

Command palette

What it does. Jump to any board, card, clip, chronicle, doc, or process — and run actions like new card, new clip, new chronicle, or start/stop the timer. Your last few picks sit in a Recent group when the box is empty.

How to use it. Press ⌘K anywhere.

Tip. Type a few letters of anything — the palette fuzzy-finds it.

Global search

What it does. Search cards, clips, comments, board docs, and chronicle entries across the whole workspace.

How to use it. The magnifier at the bottom of the activity rail — click or press ⌘K and type.

Notifications

What it does. Overdue and upcoming due cards from every board, plus a shortcut to the running timer.

How to use it. The bell at the bottom of the activity rail — the badge counts cards due today or already overdue.

Tip. Click a card to open it; set due dates on cards to feed the list.

Sidebar

What it does. Boards and board groups — your workspace outline.

How to use it. Drag boards to reorder or into groups; drag group headers to rearrange. Click the Board icon again (or ⌘\) to hide and show it.

Tip. Inbox is the default board — it can't be deleted, everything else can.

Card details

What it does. Clicking a card opens its full detail — title, description, checklist, labels, comments, attachments.

How to use it. Details open docked on the right or centered as a dialog — pick your preference in Settings → Appearance.

Right-click

What it does. Context menus live on almost everything — cards, chips, tabs, days, rows, doc entries.

How to use it. Right-click (or Ctrl-click) to see what a thing can do.

Drag & drop

What it does. Reorder cards, columns (⋮⋮ grip), boards, tabs, and reschedule due dates.

How to use it. Drag — a line or highlight marks where it lands.

🗂Board & cards

The Board view is a kanban workspace: cards live in columns on boards, grouped into board groups. Cards carry the work — details, checklist, comments, attachments — while columns and groups carry the structure.

Cards

What it does. Tasks with rich descriptions, comments, attachments, labels, due dates, subtasks, and estimates.

How to use it. Add a card with the column's + button, or paste a list for bulk add. Click a card for the full dialog — the Links row ties related cards together. Right-click → Card color tints the card; Duplicate clones it. Move To → another board's name moves a card (with its subtasks) to that board. The toolbar's done/total chip opens a per-column breakdown. Double-click a column's name to rename it.

Tip. Type #tag in a card title to attach (or create) that label. Paste a multi-line list into an add-card input to create a card per line — works for subtasks too.

Comments & attachments

What it does. Every card has a comment thread with the full rich editor, plus file attachments — images open in a zoomable lightbox.

How to use it. Open a card → Comments or Attachments. Comments autosave a draft per card.

Columns

What it does. Columns own a color accent and an order.

How to use it. Rename via the column menu; drag the ⋮⋮ grip to reorder.

Upcoming rail

What it does. Everything due soon or overdue, across all boards.

How to use it. Toggle the right rail from the board toolbar — red = overdue.

Archived items

What it does. Done-for-good cards leave the board but never vanish — browse and restore them from the Archived view.

How to use it. Sidebar → Archived.

Exports

What it does. Board CSV export for spreadsheets and sharing.

How to use it. Board context menu → Export CSV… lands in ~/Downloads.

📄Board documents

Each board has an Overview surface: a brief at the top and a list of long-form documents underneath — decisions, designs, research — that live next to the cards they describe.

Board docs

What it does. Rich documents per board — briefs, decisions, designs, research. Each doc is a feed of typed entries with comments.

How to use it. Open a board → switch to the Overview surface → ＋ New doc in the docs rail.

  1. Open a board and click the Docs rail
  2. New document → give it a title
  3. Pick an entry kind and write — every rich block works here
  4. Add comments on entries, link work items, pin or archive the doc
  5. Export → Markdown to share a doc as a file

Tip. Entries carry a kind chip (note/decision/design/discussion/research); comments open in a popup — the count pill or the chat icon on any entry.

Board brief

What it does. A standing description of the board's mission — always one click away.

How to use it. Board → Overview surface → Brief card at the top. Edit inline and save.

Tabs

What it does. Organize a doc's entries into named sections — Research, Decisions, anything. Entries move between tabs; removing a tab sends its entries back to General, nothing is lost.

How to use it. The tab row above the entries — + creates a tab, right-click a tab to rename, reorder, or remove it. The folder icon on an entry moves it.

  1. Click + on the tab row and name the section
  2. New entries post into whichever tab is selected
  3. Move entries via the folder icon on each card
  4. Right-click a tab → Remove: entries land in General

Tip. All entries shows every section together (read-only). Each tab keeps its own draft.

Feed filters, sorting & day groups

What it does. Long feeds stay readable: filter by entry kind or text, sort by date, edit recency, comment count, or entry type, and entries group under Today / Yesterday / date headers.

How to use it. The chip row, search box, and sort menu above any doc or chronicle feed. The sort is remembered per doc and chronicle.

Drafts follow you

What it does. Half-written entries are kept per doc and per chronicle — switch away and come back, your text is still there.

How to use it. Just type; the draft persists until you post or clear it.

Archive & copy

What it does. Docs and chronicles archive instead of deleting; entries copy their text to the clipboard in one click.

How to use it. Doc ⋮ menu → Archive; rail → Show archived. Copy is the icon on any entry.

✎Rich editing

Card descriptions, board docs, and chronicle entries all use the same block editor. Type / for the block menu, select blocks to turn them into something else, or just paste — the editor figures out tables, diagrams, and formatting.

Block menu

What it does. Every rich block lives in one menu: Callout, Toggle, Contents, Divider with label, Status pill, Key-value block, Timeline, Diagram, Visual diagram, Inline math, AsciiMath formula, File attachment, Bullet list, Numbered list, Checklist, Code block, Quote, Table, and Divider.

How to use it. Type / at the start of a line or after a space mid-sentence, or click the ＋ in the toolbar — then pick a block.

  1. Click into any entry or comment composer
  2. Type / and pick a block (or use the ＋ button)
  3. Fill it in — ⌘⏎ saves the whole entry

Tip. The / menu converts the line you're on — type a title first, then /toggle to make it the toggle's title.

Toggles & outliner

What it does. Collapsible rows that nest — Enter makes a sibling row, Tab indents under the row above, Shift-Tab or Backspace lifts back out.

How to use it. Insert a Toggle, type a title, then drive with Enter / Tab / Shift-Tab / Backspace like an outliner.

Code & diagrams

What it does. Syntax-highlighted code blocks with a language picker, plus mermaid diagrams and AsciiMath formulas that render live. Inline math chips flow inside sentences, list items and table cells.

How to use it. /visual opens a drag-and-drop canvas editor — pick a template (hub-and-spoke, flowchart, org chart, network topology, multi-step process, sequence) or start blank; blank drops a starter box already in typing mode and Tab adds the next connected box. Add shapes three ways: click a palette shape to place it (connected beside the selection), drag it onto the canvas, or double-click empty canvas for a box. Type directly into a selected box — Enter adds a new line, ⌘⏎ or clicking away commits; hover a box's + dots for a ghost preview, click to spawn a connected copy, or drag a dot onto another box to draw an arrow (drop on empty canvas for a shape picker). The palette's Arrow button opens a flyout of connector presets — arrow, both-ends, plain line, straight, curved — pick one and drag between boxes (or grab a line anywhere and pull to bend it, drag an endpoint dot onto any box to reconnect, double-click the line to label it, or insert a box mid-arrow). Selecting a line gives a floating bar with connector-type buttons (straight/elbow/curved), head presets (none/end/start/both), colour and line style; the ⋯ row adds per-end head shapes, thickness and dotted lines. The compact style bar anchors beside the selection — shape, fill, text — with a ⋯ popover for opacity, border and alignment; press ? in the editor for the shortcut sheet (⌘C/⌘V/⌘X, ⌘D, Alt-drag duplicate, Shift-drag marquee, arrows nudge). Layout + direction controls auto-arrange; diagrams render inline with the app theme. /diagram (mermaid) or /asciimath shows a picker — diagram types (flowchart, sequence, containers…) or starter formulas (quadratic, sum, integral, matrix) — each seeds working syntax you can edit. The ? chip on a block opens a syntax hints popup; click a snippet to insert it at the caret. For a formula inside a sentence, type $x^2$ or /math or select text and click √x. Diagrams also drop inside bullet items, numbered items and table cells — they land under the cell's or item's text, never replacing it.

Tip. Pasting diagram source offers 'Insert as diagram?' — one click to render it.

Mentions & references

What it does. Mention a work item with @ — it becomes a chip with a live status dot that opens the card when clicked.

How to use it. Type @ in a composer and pick a card.

Smart paste

What it does. Pasted tables, mermaid source, preformatted text and literal HTML markup are recognized — preview and insert them properly, or keep as text. Pasted HTML is sanitized (scripts, embeds and remote content are stripped) and becomes editable native content.

How to use it. Paste — a small dialog asks how to handle it when the content is detected. For HTML you can insert formatted, keep it as an HTML code block, or keep it as plain text.

Marks & colors

What it does. Bold, italic, strikethrough, ==highlight==, text color, font, alignment, links, and date tokens.

How to use it. The toolbar above the composer keeps inline formatting only; highlight is the ▨ button (⌘⇧H). Lists, checklists, code, quotes and tables live in the / menu (or select text → Turn into).

📋Clips & Quick Paste

Clips is a vault for text you reuse: boards → tabs → panels → clips. Nothing is captured in the background — you save exactly what you choose — and the global quick-paste shortcut brings it to any app.

Clips

What it does. Saved snippets — text, code (with language), links, files, images, templates, forms.

How to use it. Tabs → panels → clips. Click a chip to edit it; right-click for copy, pin, menus, and more.

Tip. Pin frequent clips; mark secrets — they stay masked until revealed.

Quick paste

What it does. A floating picker that pastes a clip into whatever app you're in — even when Trakisilo isn't focused.

How to use it. Press ⌘⇧V from anywhere. The shortcut is configurable in Settings → General → Quick-paste shortcut.

  1. Save a clip in Clips
  2. In any app, press the quick-paste shortcut
  3. Type a few letters to filter, Enter to paste
  4. Change the combo in Settings if it clashes with another app
  5. On macOS, auto-paste needs Accessibility permission — the picker links straight to the setting (copy mode works without it)

Paste menus & tray

What it does. Curated clip menus for instant pasting from the menu bar. Menus can be reordered — the first one feeds the tray.

How to use it. Clips ⋮ → Paste menus — they feed the tray icon. The editor's menu strip reorders them (first = tray). Closing the window keeps Trakisilo running in the tray — use the tray's Open/Restart/Quit to manage it.

Organize

What it does. Drag-reorder chips, panels, and tabs.

How to use it. ⋮ → Organize to enter drag mode.

⏱Time & Leave

Time tracking is tied to your cards: start a timer on the card you're working on, or log time by hand. The Time view rolls it up into weekly timesheets and reports, and Leave keeps non-working days out of the math.

Tracker

What it does. Running timer tied to a card or project — a pill follows you across views.

How to use it. ▶ on a card, in the Time view, or ⌘K → Start timer.

Timesheet

What it does. Weekly grid — log time directly into day cells. Entries spanning midnight credit each day its share.

How to use it. Click a cell to log; identical entries collapse into ×N groups.

Reports

What it does. Totals, per-project share, and 14-day bars.

How to use it. Time view → Reports tab; CSV export available.

Leave days

What it does. Mark a day as leave — hatched on the calendar, 🌴 header on the timesheet.

How to use it. Right-click a calendar day or a timesheet day head → Mark as Leave.

⚙Processes

Processes are reusable checklists: build a template once — release steps, onboarding, a packing list — then run it as many times as you need, with notes and history on every run.

Templates

What it does. Reusable checklists — your gold standard for repeat work, with phases, form fields, conditional steps, and pitfalls.

How to use it. Processes → New process (wizard) or start from a starter template.

Runs

What it does. Execute a template: tick steps, add notes, verify, pause/resume.

How to use it. Pick a process → ▶ Run. Every run is saved to history.

Tip. Stop steps block progress until done — use them for gates like sign-offs.

🧵Chronicle

Chronicle is a typed, append-only journal for each board — notes, releases, decisions, risks. Sections split a long journal into named parts, and feeds with filters and sorting keep it readable as it grows.

Chronicles

What it does. Append-only topic logs — releases, decisions, risks — as a dated timeline with comments on each entry.

How to use it. Create a chronicle in the left rail, pick an entry type, write, Add entry.

  1. Rail → + to create a chronicle
  2. Pick a type chip (note/release/decision/risk) and write an entry
  3. Comment on entries, filter and sort the feed, archive when the topic closes
  4. Export → Markdown from the chronicle menu

Tip. Entry types are editable later via Edit; comments open in a popup — the count pill or the chat icon on any entry.

Chronicle sections

What it does. Split a chronicle's timeline into named sections — Decisions, Incidents, follow-ups. All entries still shows the whole log; each section keeps its own draft.

How to use it. Sections nest under the chronicle's row in the left rail — click to filter the page. ＋ New section creates one; right-click a section to rename, reorder, or delete it. Deleting returns its entries to General.

💾Data, sandbox & settings

Everything lives in a local SQLite file plus an attachments folder — no account, no sync, no telemetry. Back it up, restore it, try the throwaway demo sandbox, and make it look like yours.

Local-first storage

What it does. One local SQLite database + an attachments folder — no account, no cloud, works offline.

How to use it. Settings → General explains the layout; everything lives under app data.

Backup & restore

What it does. Snapshot the database + attachments to a folder you choose; restore replaces the workspace (after auto-backing-up).

How to use it. Settings → Data → Backup / Import backup.

  1. Settings → Data → Backup → pick a folder
  2. Restoring? Import backup — the app snapshots current data first, then swaps in the backup

Recently deleted

What it does. Deleted cards and clips sit here for 30 days — restore them in full (subtasks, comments, attachments) or purge them early.

How to use it. Settings → Recently deleted → ↩ restores, 🗑 deletes forever.

Demo sandbox

What it does. A throwaway workspace where the app drives itself — boards, docs, clips, chronicles, time, processes.

How to use it. Settings → Guide → Run the demo. Pick a pace (🐢 Relaxed · 🚶 Normal · ⚡ Fast); ←/→ step manually, Space pauses. Exit via the pill — real data is untouched.

Appearance & shortcuts

What it does. Theme (system/dark/light), accent hue, background preset, ambience (Rich/Calm), contrast, text size — and the quick-paste shortcut is yours to change.

How to use it. Settings → Appearance, or ⌘K → theme commands. The quick-paste combo lives in Settings → General.

★Pro tips

⌘⇧V works even when Trakisilo is unfocused — the picker floats over your other apps.

Half-written entries are never lost — drafts follow the doc or chronicle they belong to.

Type @ in any composer to link a work item — the chip shows its live status.

Paste mermaid source and it offers to render as a diagram — no code block needed.

Every feed has kind chips + a filter box — long histories stay navigable.

Archive instead of deleting — docs, chronicles, and cards all come back when you need them.

The demo sandbox can't hurt your data — every change lives in a throwaway workspace.

Secret clips render •••••• until you reveal them — safe to share your screen.
