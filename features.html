Features

Everything in one workspace

Every clip below is the real app, recorded live — no mockups. Free, offline, no account.

01

Kanban boards

Plan work visually on columns you define — with groups for the different areas of your life.

  • Unlimited boards, organized into named groups
  • Custom columns — rename, reorder, add your own
  • Drag cards between columns, or move via the right-click menu
  • Done/total counters per column, board stats at a glance
  • Paste a multi-line list to create many cards at once

02

Card detail

Every card opens into a full page — the description is a rich editor, not a plain textarea.

  • Rich description with formatting, links and blocks
  • Subtasks with progress tracking
  • Comments keep discussion next to the work
  • Labels, priority, estimates, due dates, card colors
  • Card links connect related tasks
  • File attachments — images preview and zoom inline

03

Saved clips

A vault for everything you paste repeatedly — organized into boards and panels.

  • Text, code, links, emails, images, tables and file paths
  • Code clips keep syntax highlighting per language
  • Boards and panels keep large collections tidy
  • Link clips to tasks so they're one click from the work
  • Explicit saves only — nothing is captured in the background

04

Quick-paste

Your clips are never more than two keystrokes away — in any app on your machine.

  • A global hotkey opens the floating picker from anywhere
  • Type to filter — Enter pastes and closes
  • Copy vs paste actions, and a fully customizable shortcut
  • Works in every app — the picker floats above all windows

05

Time tracking, timesheets & reports

Track where the hours actually go — timers tied to real tasks, or manual entries after the fact.

  • One-tap timers with live ticking, or log time manually
  • Overlap warnings keep the timeline honest
  • Leave days excluded from the totals
  • Weekly timesheet grid with daily totals
  • Reports grouped by board, label or task — CSV export

06

Calendar

See deadlines and logged time on one calendar — plan the week at a glance.

  • Month and week views
  • Due tasks and time entries on the same grid
  • Entries tinted by the board they belong to

07

Chronicle

A typed journal that answers "what did I actually do this week" — and where the release notes write themselves.

  • Typed entries — notes, decisions, releases, risks
  • Rich blocks inside entries: checklists, code, tables
  • Per-entry comments and annotations
  • Filter by type; search across chronicles

08

Board docs

A per-project document feed living next to the board — decisions and specs that survive the task that spawned them.

  • Docs per board, typed: note, decision, design, discussion, research
  • Multiple entries per doc, each with its own comments
  • Link docs to the cards they describe
  • The brief line at the top keeps the goal visible

09

Rich editor

The same editor powers card descriptions, comments, chronicle entries and board docs — type, then transform.

  • Code blocks with syntax highlighting and pretty print
  • Tables with real row and column borders
  • Collapsible toggles — Tab indents into subtoggles
  • Callouts, quotes, checklists, timelines, status pills
  • Mermaid diagrams render inline
  • Select text → Turn into converts it to any block

10

Processes

Turn work you repeat into a checklist you never have to rebuild.

  • Guided wizard captures name, objective, prerequisites, pitfalls
  • Steps group into phases — progress tracked per run
  • Runs are lightweight — tick through, add notes, verify
  • Perfect for releases, onboarding, weekly reviews

11

Search & command palette

⌘K — or Ctrl+K — jumps to any card, clip, doc or view without touching the mouse.

  • Instant results across every surface — tasks, clips, chronicles, docs, processes
  • Quick actions: new board, new group, jump to a view

12

Make it yours

System, dark and light themes — plus accent color, contrast slider, text scaling, and custom statuses and label colors per board.

  • System, dark and light themes
  • Accent color and contrast controls
  • Text scaling for readability
  • Custom task statuses and label colors per board
